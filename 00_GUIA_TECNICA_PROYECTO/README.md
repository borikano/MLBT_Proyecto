# Guía técnica del proyecto MLBT

Esta carpeta centraliza la navegación técnica del repositorio `MLBT_Proyecto`.

No reemplaza la documentación existente. Su propósito es facilitar la lectura, ejecución, revisión y trazabilidad del proyecto desde un punto de entrada claro.

## Proyecto
