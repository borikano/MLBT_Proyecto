# Resumen técnico

## Proyecto

MLBT Project - María La Bonita Taquería.

## Objetivo

Organizar y documentar el proyecto MLBT como repositorio público verificable, incluyendo código fuente, módulos web, API, base de datos, pruebas, evidencias y trazabilidad Git.

## Módulos principales

| Módulo | Propósito |
|---|---|
| `api-mlbt` | API REST desarrollada con Node.js, Express, Prisma y MySQL/MariaDB. |
| `spring-web` | Módulo web Java/Spring asociado a evidencias anteriores. |
| `java-web` | Módulo web Java asociado a evidencias anteriores. |
| `docs` | Documentación técnica y evidencias. |
| `assets`, `css`, `js`, `pages` | Recursos de presentación y frontend base. |

## Tecnologías identificadas

- JavaScript / Node.js
- Express
- Prisma
- MySQL / MariaDB mediante XAMPP
- Postman
- Java / Spring Boot
- Git y GitHub

## Estado

Proyecto disponible para revisión técnica en la rama estable `Arawkano`.
