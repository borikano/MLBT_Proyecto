# Resumen técnico

## Proyecto

MLBT - María La Bonita Taquería.

## Objetivo

Organizar y documentar el proyecto MLBT como repositorio público verificable, incluyendo interfaz React, módulos web, API, pruebas, evidencias y trazabilidad Git.

## Módulos principales

| Módulo | Propósito |
|---|---|
| frontend-react | Interfaz React desarrollada para AP07. |
| api-mlbt | API REST desarrollada con Node.js, Express, Prisma y MySQL/MariaDB. |
| spring-web | Módulo web Spring asociado a evidencias anteriores. |
| java-web | Módulo web Java asociado a evidencias anteriores. |
| docs | Documentación técnica y evidencias. |
| pages, css, js, assets | Interfaz base del proyecto. |

## Estado

Proyecto disponible para revisión técnica en la rama Arawkano.
