# Estructura del proyecto

## Estructura raíz

| Ruta | Propósito |
|---|---|
| README.md | Presentación principal del repositorio. |
| LICENSE.md | Licencia MIT aplicable al código propio del proyecto. |
| 00_GUIA_TECNICA_PROYECTO | Entrada técnica organizada para lectura y revisión. |
| 01_FRONT_END | Bloque de interfaces del proyecto. |
| 01_FRONT_END/01_REACT_AP07 | Interfaz React del proyecto MLBT para AP07. |
| 01_FRONT_END/02_INTERFAZ_BASE | Interfaz base HTML, CSS, JavaScript y recursos visuales. |
| 02_BACK_END | Bloque de módulos de servidor y servicios. |
| 02_BACK_END/01_API_NODE | API REST del proyecto MLBT. |
| 02_BACK_END/02_SPRING_WEB | Módulo web Spring Boot. |
| 02_BACK_END/03_JAVA_WEB | Módulo Java Web con JSP y Servlets. |
| 03_DOCS | Documentación técnica, estándares, trazabilidad y evidencias. |

## Criterio aplicado

El repositorio se organiza por responsabilidad técnica. El Front End conserva las interfaces, el Back End conserva servicios y módulos Java, y 03_DOCS concentra documentación, evidencias y trazabilidad.

La guía técnica funciona como panel de revisión, mientras que cada módulo conserva su propio README para facilitar navegación desde GitHub.
