# Comandos de ejecución

## Interfaz React

Ubicación:

    Set-Location "E:\Dev\01_Repositorios\MLBT_Proyecto\front-end\react-ap07"

Instalación:

    pnpm install

Ejecución local:

    pnpm dev

Dirección local:

    http://localhost:5173

Validación:

    pnpm lint
    pnpm build

## API MLBT

Ubicación:

    Set-Location "E:\Dev\01_Repositorios\MLBT_Proyecto\back-end/api-node"

Instalación:

    pnpm install

Ejecución local:

    pnpm run dev

Dirección local:

    http://localhost:3001

## Spring Web

Desde la raíz del repositorio:

    .\back-end/spring-web\mvnw.cmd -f .\back-end/spring-web\pom.xml spring-boot:run

Dirección local:

    http://localhost:8082
